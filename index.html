실시간 티켓 예약 동시성 제어 시뮬레이션

선착순 예약 대규모 동시 요청 상황을 시뮬레이션하고, 데이터 정합성을 유지하며 처리 속도를 튜닝해 보는 개인 학습용 프로젝트입니다. 데이터베이스 비관적 락(Pessimistic Lock)과 Redis 분산 락(Redisson)의 적용 결과를 다각도로 비교 분석했습니다.

  • Redisson 분산 락을 설계·구현하여 1,000건의 동시 예약 요청에서 초과 예약 건수 0% 달성
  • 낙관적 락(Optimistic Lock) 재시도 루프 병목 지점과 비관적 락의 데이터베이스 Lock 획득 대기 지표 비교
  • JMeter 부하 테스트를 진행하여 병목 지점을 찾고 최적의 락 해제 타임아웃 설정을 정의

2023.11 ~ 2023.12 Dev Course Team Project

RESTful 쇼핑몰 서비스 백엔드 API 및 쿼리 개선

기초 도메인 설계를 기반으로 객체지향적인 회원, 주문, 결제 도메인 API를 구축한 웹 교육 프로젝트입니다. QueryDSL을 활용하여 복잡한 다중 필터 조회 시 발생하는 쿼리 및 데이터베이스 접근 병목을 개선했습니다.

  • QueryDSL과 Spring Data JPA의 Fetch Join을 활용해 연관관계 탐색 시 발생하는 N+1 문제 해결
  • 상품 테이블 내 복합 인덱스(Compound Index) 설계를 통해 상품 데이터 10만 건 기준 조회 쿼리 속도 3.2초에서 0.15초로 단축
  • Spring Security와 JWT를 연동해 인증 필터 로직 구현 및 Refresh Token 기반 토큰 자동 재발행 구현
